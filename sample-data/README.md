# Sample Data

This directory contains a small sample of the telemetry generated by Operation Black Beacon.

The full incident dataset contains:

- 150 normal events
- 30 suspicious events
- 20 benign distractors
- 200 total events

The public repository includes only a small sample to demonstrate the JSON Lines schema without publishing the complete investigation dataset.

## Example Fields

Each event contains fields such as:

- `time`
- `event_category`
- `event_action`
- `user`
- `src_ip`
- `dest_ip`
- `host`
- `application`
- `resource`
- `result`
- `severity`
- `message`
